### 1.2 已排除（2026-11-11 實測，不再評估）

- Google Open Buildings v3、Microsoft GlobalMLBuildingFootprints：台灣無涵蓋
- Google Maps Platform（3D Tiles / Elevation / 2D Tiles）：需計費且政策禁止快取與衍生
- NLSC MapSearch API：回應為 Java 序列化的 `null`，不可用
- Open CAD Studio 第三方插件（Terén / Land Survey / Raster Tools / Open Infra）：runner 可載入但本機 build 未註冊任何指令與功能區分頁，無法使用

### 1.3 關鍵缺口

1. `pipeline.py` 仍是**完全平坦**模型：建物高度 = 屋頂高 − 地面高，地面單一高程，無地形概念
2. `app/survey.py` 的 `TerrainGrid` 尚未接進 pipeline
3. 建物資料仍來自 3DBAG（荷蘭），OSM 建物缺高度比例很高（實測：高雄亞洲新灣區 105 棟中僅 13 棟有 `height`、25 棟有 `building:levels`）
4. 介面、說明文字、3MF metadata 全為荷蘭文
5. 座標系硬寫 `EPSG:28992`（RD New）

## 2. 目標與驗收標準

**總目標**：使用者輸入台灣任一地號／地址／範圍，輸出可分色列印的 3D 模型（STL / 3MF），且地面高程來自真實地形資料。

| 編號 | 驗收項目 | 門檻 |
|---|---|---|
| A1 | 座標正確性 | 同一點在 EPSG:3826 的座標與內政部 TGOS 查詢結果誤差 < 1 m |
| A2 | 地形精度（測量圖模式） | 留出測點 RMSE ≤ 0.60 m（現行 0.491 m） |
| A3 | 地形合理性（DTM 模式） | 與 20 m DTM 取樣比對，測量圖網格中位差 ≤ 1.0 m |
| A4 | 建物覆蓋率 | 測試區（台北信義、台中七期、高雄亞洲新灣區、花蓮市）OSM 建物 ≥ 90% 能取得足跡 |
| A5 | 建物高度可用率 | 有 `height` 或 `building:levels` 者 + 推估模型覆蓋，全部建物 100% 有高度 |
| A6 | 可列印性 | `verify_output.py` 通過；單一 3MF < 50 MB；底板翹曲區塊無孤立薄片 |
| A7 | 分色帶 | 底板／地形／道路／綠地／建物各自落在設定的 Z 帶，換料次數 ≤ 6 |
| A8 | 中文介面 | 網頁、錯誤訊息、3MF metadata 無荷蘭文殘留 |

## 6. 已定案技術決策

| 編號 | 決策 | 理由 |
|---|---|---|
| D1 | 地形內插預設用 **Delaunay TIN** | 崙背實測 RMSE 0.491 m vs 調和 0.599 m（準 18%），且與測量軟體慣用做法一致 |
| D2 | 不採用 Open CAD Studio 第三方插件 | 本機 build 載入後不註冊指令與 UI，無法程式化操作 |
| D3 | DTM 讀取優先評估 `rasterio`，其次 GDAL | 純 wheel 安裝較容易打包；需實測 Windows 離線安裝 |
| D4 | `*_rd` 命名暫不改 | 純命名問題，改動面大且無功能收益；待 W3 完成後再一次性處理 |
| D5 | 異常測點以等高線高程範圍 ±max(5 m, 25% 高差) 判定 | 已過濾掉崙背圖中 2 個 z=123.46 的圖框角點 |

## 7. 風險登錄表

| # | 風險 | 影響 | 機率 | 對策 |
|---|---|---|---|---|
| R1 | OSM 建物高度缺失率高（實測僅 12–24% 有標籤） | 模型外觀失真 | 高 | W4 推估模型 + UI 標示推估比例；必要時改用內政部 3D 建物模型（需另行評估授權與格式） |
| R2 | Overpass 查詢逾時或限流 | 使用者等待失敗 | 高 | 分區塊查詢、指數退避重試、磁碟快取；必要時自架 Overpass |
| R3 | 20 m DTM 精度不足以表現平坦區微地形 | 底板高低差錯位 | 中 | 平坦區改用測量圖模式；DTM 僅作大範圍底色 |
| R4 | 測量圖圖層命名不統一（`C1`/`C5` 只是本案慣例） | 別家圖面解析失敗 | 高 | `CONTOUR_KEYWORDS` 已含中英關鍵字；W3.2 需加「圖層對應」預覽與手動指定 |
| R5 | 高程異常點（圖框角點、樁位表）污染內插 | 地形爆高 | 中 | 已實作 `filter_outliers`；再加水準點/圖框圖層黑名單 |
| R6 | 地形加入後列印高度預算不足 | 建物被壓扁 | 中 | W3.4 自動重分配 Z 帶；提供「地形誇張倍率」參數 |
| R7 | DTM 101 MB 隨安裝檔散佈 | 安裝檔過大 | 低 | 首次啟動下載 + 校驗碼；或只附目標縣市 |
| R8 | 大量圖磚／建物造成記憶體尖峰 | 當機 | 低 | 沿用快取與分塊處理，加請求上限 |
